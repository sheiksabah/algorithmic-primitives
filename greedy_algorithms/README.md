# Greedy Algorithms

This directory contains greedy algorithms implemented from scratch in Python to practice algorithm design, problem-solving, and optimization.

## Algorithms

### Activity Selection

Selects the maximum number of non-overlapping activities from a list of activities, where each activity is represented by a start time and a finish time.

- **Greedy Strategy:** Select the compatible activity that finishes earliest.
- **Time Complexity:** `O(n log n)` due to sorting.
- **Space Complexity:** `O(n)` for the sorted activities and selected results.
- **Implementation:** `activity_selection.py`
